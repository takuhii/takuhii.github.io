# Susy-Sass (light theme)

Documentation pages for **Susy-Sass**, a responsive grid/layout engine for Sass.

- Live: <https://takuhii.github.io/susy-sass/>
- Theme: light (original stylesheet)

This is the light-themed copy of the Susy-Sass documentation pages. A
dark-themed copy of the same pages lives in [`../susy-sass3`](../susy-sass3),
which loads an inverted version of this stylesheet. The theme is a page-styling
choice only and does not change the Susy-Sass layout engine.

See the [repository README](../README.md) for the full project overview and
deployment details.
