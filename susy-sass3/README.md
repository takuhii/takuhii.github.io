# Susy-Sass3 (dark theme)

Documentation pages for **Susy-Sass**, a responsive grid/layout engine for Sass.

- Live: <https://takuhii.github.io/susy-sass3/>
- Theme: dark (inverted stylesheet)

This is the dark-themed copy of the Susy-Sass documentation pages. It uses a
fully inverted (photographic-negative) version of the stylesheet from
[`../susy-sass`](../susy-sass), giving the pages a dark appearance that mirrors
the light original. The theme is a page-styling choice only and does not change
the Susy-Sass layout engine.

See the [repository README](../README.md) for the full project overview and
deployment details.
